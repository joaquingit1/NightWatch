## Concepts

### 01 — Midnight Sentinel

Dark navy command-interface treatment with a wireframe robot dog, radar geometry,
electric-blue controls, and strong system-status cues. This has the most immediate
booth-demo impact.

### 02 — Aurora Care

Midnight indigo, cyan, and lavender glass layers. It keeps the technological
language while feeling calmer and more supportive for tired visitors.

### 03 — Future Lab

Bright editorial robotics interface with blueprint linework and concise capability
chips. This is the clearest and most implementation-friendly direction.

## Prompt set

All three prompts requested a shippable 9:16 mobile web interface rather than
concept art. They used the same consent question and practical interaction model,
while varying only the art direction:

1. Calm dark HUD with restrained scan/radar details.
2. Gentle aurora wellness-tech with soft translucent layers.
3. Pearl-white Swiss editorial grid with cobalt technical linework.

The prompts explicitly excluded medical claims, invented analytics, surveillance
imagery, device frames, browser chrome, tiny illegible UI copy, and watermarks.
